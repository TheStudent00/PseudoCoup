# SUPPORT_BRAINSTORM — hub

Stage: brainstorm (the `SUPPORT_BRAINSTORM_` convention: a proposed shape,
not a ruled one). Opened 2026-10-09 at Dee's word: "we can make notes in
brainstorming documents so we dont have to re-think the ideas weve already
thought-up." Nothing here is ruled; what is ruled is in the CORE.

The Hub is "a modified Python language" (Dee, 2026-10-09) that holds AutoPoly.
These are the ideas raised so far about its operators (§1), and, since
2026-10-10, about the structure and the holders AutoPoly must understand
(§2), and, since 2026-10-14, about emulating one language's HiOps with
another language's HiOps (§3), kept so they are not thought up a second time. Each says whose it is: **Dee** (Dee's own words),
**mine** (Claude's reading or recommendation, never a decision), or **the
August research** .

Dee's word on when to come back to §1, 2026-10-09: "yeah okay, lets leave
it for later. we will have a clear picture once everythings ready for
constructing the Hub." On §2, Dee, 2026-10-10: "structural comprehension is
needed sooner, rather than later."
