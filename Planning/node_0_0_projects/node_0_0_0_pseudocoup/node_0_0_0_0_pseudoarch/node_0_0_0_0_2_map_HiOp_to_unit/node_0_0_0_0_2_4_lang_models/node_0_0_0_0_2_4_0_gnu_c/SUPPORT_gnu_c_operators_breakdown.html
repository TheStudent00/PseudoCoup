GNU C's operators: simple, complex, and the rest

Figure 1. Every operator clang 21.1.8 accepts in GNU C on riscv64, by class: in all. The 95 expressions and statements are named by clang's kind and entry (BinaryOperator.Mul, which a program writes as a * b). The 1,185 builtins are named by their builtin name. Each operator counts 1. The centre is the whole; each ring outwards is one level down.

What it does not show. HiOp variants, meaning an operator with its holders. For the 95 expressions and statements, and for 187 of the builtins, clang states the holders only in C++ code (its checking), so they are not counted here. Also outside the figure: 69 builtins for other languages, other targets, or behind flags that are off; clang's internal expressions no program writes; and constants and names, which are not operators.
